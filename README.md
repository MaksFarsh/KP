## Постановка задачи
Датчик технологической установки непрерывно формирует последовательность показаний электропроводности смеси X (диапазон значений от 0.5 до 20 мСм/см). В программной реализации 40 показаний последовательно считываются из файла. Каждое показание X преобразуется по индивидуальной кусочной функции в индикатор технологического процесса Q: при X < 3 применяется формула 6·√(X-3+1) + 5, при 3 ≤ X ≤ 10 — формула 2·(X-6.5) + 50, при X > 10 — формула 0.25·(X-10)² + 55.
